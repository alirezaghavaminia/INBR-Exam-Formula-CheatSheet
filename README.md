# برگه خلاصه فرمول‌های ضروری برای آزمون نظام مهندسی ساختمان رشته‌ی تاسیسات ساختمان (مهندسی مکانیک)

این برگه‌های فرمول که می‌بینید خلاصه فرمول‌هایی هست که من با بررسی سوال‌های ۱۵ سال اخیر برای آزمون خودم نوشتم و برای این که بین فایل‌های سیستم گم نشه گذاشتمشون اینجا. شما هم می‌تونید ببینید و استفاده کنید ولی اگر می‌خواید استفاده کنید بدونید که: 

- من درست بودن این‌ها را تضمین نمی‌کنم. با ریسک خودتون استفاده کنید و حتما چک و بررسی کنید. 
- در پروژه‌های واقعی استفاده نکیند (چون پر از تقریب‌های مشکوک هستن)
- استفاده‌ی تجاری (پکیج فروشی و ...) هم مجاز نیست.
